SQL Comparison (/sql)

Parameter Type Required Rules / Accepted Values
db1_sqlstringConditionalRequired with db2_sql when using text mode.
db2_sqlstringConditionalRequired with db1_sql when using text mode.
db1_filefileConditionalRequired with db2_file when using upload mode. Must be .sql and non-empty.
db2_filefileConditionalRequired with db1_file when using upload mode. Must be .sql and non-empty.
query_pair_idstringNoOne of predefined SQL query pair IDs. Defaults to first pair.
warmup_runs_rawintNoClamped to 0 to 10. Default 1.
measured_runs_rawintNoClamped to 1 to 30. Default 6.
use_llmbool-like stringNoAccepted truthy values: 1, true, yes, on.

Mode behavior: if both db1_sql and db2_sql look like executable queries, they are treated as slow/optimized benchmark queries and schema-diff is skipped.

Server requirement for LLM: GROQ_API_KEY environment variable must be configured.

FAQ Extractor (/faq)

Parameter Type Required Rules / Accepted Values
urlstringYesMust be a valid http:// or https:// URL.
crawl_depthintNoRange 0 to 5. Default 1.
max_follow_linksintNoRange 1 to 120. Default 12.
max_workersintNoRange 1 to 20. Default 8.
timeoutintNoRange 5 to 90 seconds. Default 20.
min_answer_lenintNoRange 0 to 3000. Default 20.
allow_dynamicbool-like stringNoAccepted truthy values: 1, true, yes, on. Default true.
reuse_cachebool-like stringNoAccepted truthy values: 1, true, yes, on. Default true.
use_llm_cleanupbool-like stringNoAccepted truthy values: 1, true, yes, on. Default false.

Server requirement for LLM cleanup: GROQ_API_KEY environment variable must be configured.
